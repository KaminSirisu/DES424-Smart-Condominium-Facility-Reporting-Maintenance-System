# Project documentation

- `architecture/`: system diagram, user flows, and important tradeoffs.
- `api-specs/`: OpenAPI specification or equivalent endpoint contracts.
- `database/`: DynamoDB entities, keys, indexes, and example records.
- `reports/`: course reports and presentation material approved for the repository.

The kick-off PDF is the project brief. Keep the documentation aligned with its functional requirements, and record any later scope decisions here.
